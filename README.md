# تطبيق الأفندي (أندرويد + آيفون)

التطبيق هو نفس كتالوج الموقع داخل غلاف تطبيق أصلي (Capacitor)، فيطابق الموقع تماماً:
نفس التصميم والبحث والفئات وتسجيل الدخول للأسعار وأزرار واتساب والاتصال.
الصور والمنتجات مضمّنة داخل التطبيق، فيعمل الكتالوج حتى بدون إنترنت.

```
catalog/        نسخة الموقع (index.html, assets, data, images) — ضع هنا الموقع المحدّث
shell/          إضافات التطبيق: زر الرجوع في أندرويد، فتح واتساب/الهاتف خارج التطبيق، شريط الحالة
shell/app-config.js  رابط الموقع المنشور (لزر «نسخ الرابط»)
assets/         أيقونة التطبيق وشاشة البداية
android/  ios/  مشروعا أندرويد وآيفون
.github/workflows/android-apk.yml  بناء ملف APK مجاناً على GitHub
```

## تحديث المنتجات في التطبيق
1. حدّث الموقع كالمعتاد (UPDATE_CATALOG.bat).
2. انسخ `index.html` و`assets` و`data` و`images` من مجلد الموقع إلى `catalog/` هنا.
3. ارفع التغيير إلى GitHub، فيُبنى ملف APK جديد تلقائياً.

## بناء ملف APK لأندرويد (مجاناً)
**الطريقة الأسهل:** ارفع هذا المجلد إلى مستودع على GitHub. من تبويب **Actions** شغّل «Android APK»،
وبعد انتهائه نزّل الملف `elafandy-apk` من أسفل صفحة التشغيل. انقله إلى الهاتف وثبّته
(يطلب الهاتف السماح بالتثبيت من مصادر غير معروفة مرة واحدة).

**على حاسوبك:** ثبّت Node.js وAndroid Studio، ثم:
```
npm install
npm run sync
npx cap open android      # ثم Build > Build APK(s)
```

## آيفون
- **مجاناً:** آبل لا تسمح بتثبيت تطبيقات خارج App Store. البديل المجاني هو نسخة الموقع القابلة للتثبيت
  (مجلد `website-pwa`): يفتح العميل الموقع في Safari، ثم «مشاركة» ← «إضافة إلى الشاشة الرئيسية»،
  فيظهر بأيقونة الأفندي ويفتح بملء الشاشة مثل التطبيق.
- **في App Store:** يتطلب حساب Apple Developer (‏99$ سنوياً) وجهاز Mac مع Xcode:
  `npm install && npm run sync && npx cap open ios`، ثم Product > Archive.

## Google Play (اختياري)
النشر في Google Play يتطلب حساب مطوّر (‏25$ مرة واحدة). ملف APK من GitHub يكفي للتوزيع المباشر مجاناً.
